# 原型目录

> 当前：**空壳**。L2 开始后按轮次与方案创建。

## 用途

存放 L2 方向对决、L3 单页精修用的可运行原型。原型用于**确认视觉与交互**，不是生产代码。

## 命名与隔离

```text
prototypes/
├── L2-1/                 # 第一轮方向对决
│   ├── A/                # 方案 A
│   ├── B/
│   └── C/
├── L2-2/                 # 第二轮（如需要）
└── L3-1/                 # 单页精修轮次
```

- 每个方案独立可启动，互不依赖。
- 只使用 mock 数据，**不接真实后端**。
- 不安装生产依赖到未来 `app/`；原型自己的依赖与锁文件留在方案目录内。
- 不复制原型代码进 `app/`；确认后按 `DESIGN-BASELINE.md` 重新实现。

## 何时清理

- 方案通过并写入 `DESIGN-BASELINE.md` 后，保留通过方案作为参考，其余方案可归档或删除（由主人决定）。
- 不把原型当“半成品生产代码”长期维护。
